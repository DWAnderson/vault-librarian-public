# Approved tags

One tag per line, written exactly like the examples: a dash, the tag in backticks, then what it covers.
The app adds a tag here only after you approve it, and adds folder tags itself when you file into a subfolder.

- `technology` — computers, software, gadgets, AI tools in use
- `home` — house, household and home projects
- `travel` — trips and travel planning
- `recipes` — recipes and cooking
- `thoughts` — personal reflections and ideas
- `media` — books, films, TV, music
- `finance` — personal finance and investing
- `health` — medicine, treatments, fitness
